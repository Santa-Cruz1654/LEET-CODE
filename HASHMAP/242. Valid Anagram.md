# 242. Valid Anagram

**Difficulty:** 🟢 Easy

**Topic:** HashMap, String

---

# Problem Statement

Given two strings `s` and `t`, return:

* `True` if `t` is an **anagram** of `s`.
* `False` otherwise.

An **anagram** is a word or phrase formed by rearranging the letters of another word, using **all the original letters exactly once**.

---

# Example

### Input

```python
s = "anagram"
t = "nagaram"
```

### Output

```python
True
```

---

### Input

```python
s = "rat"
t = "car"
```

### Output

```python
False
```

---

# Intuition

Two strings are anagrams if:

* They have the **same length**.
* Every character appears the **same number of times** in both strings.

Instead of sorting both strings (which takes `O(n log n)`), we can count the frequency of each character using a **HashMap**.

---

# Approach

### Step 1 — Check Length

If the lengths are different, they can never be anagrams.

```python
if len(s) != len(t):
    return False
```

---

### Step 2 — Count Characters in `s`

Traverse the first string and store the frequency of every character.

Example:

```text
s = "anagram"

Counts

a → 3
n → 1
g → 1
r → 1
m → 1
```

---

### Step 3 — Remove Counts Using `t`

Traverse the second string.

For every character:

* If it exists and its count is greater than zero, decrease the count.
* Otherwise, return `False`.

Example:

```text
Counts before:

a → 3
n → 1
g → 1
r → 1
m → 1

Process "nagaram"

n → 0
a → 2
g → 0
a → 1
r → 0
a → 0
m → 0
```

All characters match perfectly.

---

### Step 4 — Return True

If every character is successfully matched, the strings are anagrams.

---

# Python Solution

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        counts = {}

        for char in s:
            if char in counts:
                counts[char] += 1
            else:
                counts[char] = 1

        for char in t:
            if char in counts and counts[char] > 0:
                counts[char] -= 1
            else:
                return False

        return True
```

---

# Complexity Analysis

| Metric | Complexity |
| ------ | ---------- |
| Time   | **O(n)**   |
| Space  | **O(1)**   |

> **Why is space O(1)?**
> Since the strings contain only lowercase English letters, the HashMap can store at most **26** keys, which is constant space.

---

# Why This Works

* Every character in `s` increases its frequency.
* Every matching character in `t` decreases its frequency.
* If a character is missing or appears more times than expected, we immediately return `False`.
* If we finish processing `t` without any mismatch, both strings contain exactly the same characters with the same frequencies.

---

# Alternative Approach

Another common solution is to sort both strings.

```python
return sorted(s) == sorted(t)
```

### Complexity

* **Time:** `O(n log n)`
* **Space:** `O(n)`

While simpler to write, it is slower than the HashMap approach.

---

# Key Takeaways

* When comparing character frequencies, a **HashMap** is often more efficient than sorting.
* Always check simple conditions (like string length) first to avoid unnecessary work.
* Frequency counting is a common pattern used in many string and HashMap problems.
