# 392. Is Subsequence

**Difficulty:** 🟢 Easy

**Topics:** Two Pointers, String

---

# Problem Statement

Given two strings `s` and `t`, return `true` if `s` is a **subsequence** of `t`; otherwise, return `false`.

A string is a **subsequence** if we can delete some characters from the original string without changing the relative order of the remaining characters.

For example:

```text
"ace" is a subsequence of "abcde"
```

because we can remove:

```text
b, d
```

and get:

```text
ace
```

But:

```text
"aec" is NOT a subsequence of "abcde"
```

because the order of `e` and `c` is different.

---

# Approach

We use the **Two Pointer** technique.

We only need one pointer for `s` and one pointer for `t`.

- `left` → points to the current character we need to find in `s`.
- `right` → moves through every character of `t`.

Whenever:

```python
s[left] == t[right]
```

we found the next required character.

So we move:

```python
left += 1
```

We don't need to explicitly move `right` because the `for` loop handles it.

---

# Idea

Suppose:

```python
s = "abc"
t = "ahbgdc"
```

We need to find:

```text
a → b → c
```

inside `t`, while maintaining their order.

`t` is:

```text
a h b g d c
↑
```

Find `a`:

```text
a h b g d c
↑
```

Then search for `b` **after** `a`:

```text
a h b g d c
    ↑
```

Then search for `c` after `b`:

```text
a h b g d c
          ↑
```

All characters are found in the correct order.

Therefore:

```text
True
```

---

# Dry Run

### Input

```python
s = "abc"
t = "ahbgdc"
```

Initial:

```text
left = 0
```

### Traverse `t`

| `t[right]` | `s[left]` | Match? | `left` |
|------------|-----------|--------|-------:|
|`a`|`a`|✅|1|
|`h`|`b`|❌|1|
|`b`|`b`|✅|2|
|`g`|`c`|❌|2|
|`d`|`c`|❌|2|
|`c`|`c`|✅|3|

At the end:

```text
left = 3
len(s) = 3
```

Therefore:

```python
left == len(s)
```

returns:

```text
True
```

---

# Example 2

```python
s = "axc"
t = "ahbgdc"
```

We find:

```text
a
```

But after that, there is no `x` in `t`.

So:

```text
left = 1
len(s) = 3
```

Therefore:

```python
left == len(s)
```

is:

```text
False
```

---

# Python Solution

```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:

        left = 0

        for right in range(len(t)):

            if left < len(s) and s[left] == t[right]:
                left += 1

        return left == len(s)
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

Where `n = len(t)`.

### Why?

We traverse `t` only once.

```python
for right in range(len(t)):
```

Each character is checked once.

We only use the `left` pointer, so no additional data structure is required.

Therefore:

```text
Time  → O(n)
Space → O(1)
```

---

# Important Edge Case

### Empty `s`

```python
s = ""
t = "abc"
```

An empty string is a subsequence of every string.

Initially:

```text
left = 0
len(s) = 0
```

So:

```python
left == len(s)
```

is immediately `True`.

---

# Why We Don't Need Two Moving Pointers

Although this is considered a **Two Pointer** problem, `right` is automatically moved by the `for` loop:

```python
for right in range(len(t)):
```

So only `left` needs to be manually updated.

The two logical pointers are:

```text
left  → position in s
right → position in t
```

---

# Interview Takeaway

Whenever a problem asks whether one sequence/string can be obtained from another while **preserving relative order**, think:

**Two Pointers + Greedy Matching**

The pattern is:

```python
left = 0

for right in range(len(t)):

    if left < len(s) and s[left] == t[right]:
        left += 1

return left == len(s)
```

The key idea is:

> **Scan the larger string and greedily match the next required character.**
