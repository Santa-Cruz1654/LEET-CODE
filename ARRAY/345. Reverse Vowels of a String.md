# 345. Reverse Vowels of a String

**Difficulty:** 🟢 Easy

**Topics:** Two Pointers, String

---

# Problem Statement

Given a string `s`, reverse **only the vowels** in the string and return the resulting string.

The vowels are:

```text
a, e, i, o, u
```

They can appear in both lowercase and uppercase.

All consonants and other characters must remain in their original positions.

---

# Approach

We use the **Two Pointer** technique.

Place:

- `left` at the beginning of the string.
- `right` at the end of the string.

Then:

1. Move `left` forward until it points to a vowel.
2. Move `right` backward until it points to a vowel.
3. Swap the two vowels.
4. Move both pointers toward the center.
5. Repeat until the pointers meet.

Since Python strings are immutable, we first convert the string into a list.

---

# Idea

For:

```python
s = "IceCreAm"
```

The vowels are:

```text
I → e → e → A
```

We need to reverse them:

```text
A → e → e → I
```

The consonants stay exactly where they are.

Result:

```text
"AceCreIm"
```

---

# Dry Run

### Input

```python
s = "IceCreAm"
```

Convert to list:

```text
I c e C r e A m
↑             ↑
L             R
```

### Step 1

`left` points to `I` → vowel.

`right` moves from `m` to `A` → vowel.

Swap:

```text
A c e C r e I m
```

---

### Step 2

Move pointers:

```text
A c e C r e I m
  ↑         ↑
  L         R
```

`left` skips `c` and reaches `e`.

`right` skips `r` and reaches `e`.

Swap:

```text
A c e C r e I m
```

No visible change because both vowels are `e`.

---

Final result:

```text
"AceCreIm"
```

---

# Python Solution

```python
class Solution:
    def reverseVowels(self, s: str) -> str:

        s = list(s)
        vowels = "aeiouAEIOU"

        left = 0
        right = len(s) - 1

        while left < right:

            while left < right and s[left] not in vowels:
                left += 1

            while left < right and s[right] not in vowels:
                right -= 1

            s[left], s[right] = s[right], s[left]

            left += 1
            right -= 1

        return "".join(s)
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(n)** |

### Why?

The two pointers move toward each other, so every character is processed at most a constant number of times.

Therefore:

```text
Time → O(n)
```

We convert the string into a list because Python strings are immutable:

```python
s = list(s)
```

This requires:

```text
Space → O(n)
```

The algorithm itself uses only **O(1)** extra pointer space, but the character list requires **O(n)** space.

---

# Important Detail

This part:

```python
while left < right and s[left] not in vowels:
    left += 1
```

finds the next vowel from the left.

And:

```python
while left < right and s[right] not in vowels:
    right -= 1
```

finds the next vowel from the right.

Only after **both pointers find vowels** do we swap:

```python
s[left], s[right] = s[right], s[left]
```

# Interview Takeaway

Whenever a problem asks you to:

- Reverse only certain characters
- Keep other characters in their original positions
- Find matching elements from both ends
- Modify an array/string efficiently

Think of the **Two Pointer Technique**.

The general pattern is:

```python
while left < right:

    # Find valid element from left
    # Find valid element from right

    swap(left, right)

    left += 1
    right -= 1
```

This is a variation of the classic **Reverse String using Two Pointers** pattern.
