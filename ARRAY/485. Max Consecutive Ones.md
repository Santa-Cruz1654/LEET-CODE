# Problem Statement

Given a binary array `nums`, return the **maximum number of consecutive `1`s** in the array.

---

# Approach

We traverse the array once while keeping track of:

- `cnt` → Current consecutive count of `1`s.
- `max_cnt` → Maximum consecutive count seen so far.

Whenever we encounter:

- `1` → Increase the current count.
- `0` → Reset the current count to `0`.

Update the maximum count whenever the current streak increases.

---

# Idea

Initialize:

```
cnt = 0
max_cnt = 0
```

Traverse the array.

If the current element is:

### `1`

Increase the current streak.

```
cnt += 1
```

Update the maximum streak.

```
max_cnt = max(max_cnt, cnt)
```

---

### `0`

The consecutive streak breaks.

```
cnt = 0
```

Continue until the end of the array.

Return:

```
max_cnt
```

---

# Dry Run

### Input

```python
nums = [1,1,0,1,1,1]
```

| Number | Current Count | Maximum Count |
|--------|--------------:|--------------:|
|1|1|1|
|1|2|2|
|0|0|2|
|1|1|2|
|1|2|2|
|1|3|3|

Answer:

```
3
```

---

### Example 2

```python
nums = [1,0,1,1,0,1]
```

| Number | Current Count | Maximum Count |
|--------|--------------:|--------------:|
|1|1|1|
|0|0|1|
|1|1|1|
|1|2|2|
|0|0|2|
|1|1|2|

Answer:

```
2
```

# Python Solution

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:

        cnt = 0
        max_cnt = 0

        for num in nums:

            if num == 1:
                cnt += 1
                max_cnt = max(max_cnt, cnt)
            else:
                cnt = 0

        return max_cnt
```

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

### Why?

- The array is traversed exactly once.
- Only two integer variables are used.
- No additional data structures are required.

---

# Why This Works

A sequence of consecutive `1`s continues only while the current element is `1`.

Whenever a `0` is encountered:

- The current streak ends.
- The counter is reset.
- A new streak starts only if another `1` appears later.

By keeping track of the longest streak during traversal, we obtain the answer in a single pass.

---

# Interview Takeaway

Whenever a problem involves:

- Counting consecutive elements
- Longest continuous streak
- Resetting on a breaking condition
- Single-pass array traversal

Think of maintaining a **running counter** and a **global maximum**.

This pattern is common in many array and sliding-window style interview problems.
