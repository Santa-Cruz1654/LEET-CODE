# 643. Maximum Average Subarray I

**Difficulty:** 🟢 Easy

**Topics:** Array, Sliding Window

---

# Problem Statement

You are given an integer array `nums` and an integer `k`.

Find the **contiguous subarray** of length `k` that has the **maximum average value**, and return that average.

A calculation error less than **10⁻⁵** is acceptable.

---

# Approach

We use the **Sliding Window** technique.

Instead of calculating the sum of every subarray from scratch, we:

1. Compute the sum of the first window of size `k`.
2. Slide the window one element at a time.
3. Remove the outgoing element.
4. Add the incoming element.
5. Keep track of the maximum window sum.

Finally, divide the maximum sum by `k` to get the maximum average.

---

# Idea

### Step 1

Compute the sum of the first `k` elements.

```
window_sum = nums[0] + nums[1] + ... + nums[k-1]
```

Store it as the current maximum.

### Step 2

Move the window one position to the right.

For every new window:

```
window_sum = window_sum
             - outgoing_element
             + incoming_element
```

Update the maximum sum whenever a larger window sum is found.

Finally,

```
maximum average = max_sum / k
```

---

# Dry Run

### Input

```python
nums = [1,12,-5,-6,50,3]
k = 4
```

### Initial Window

```
[1,12,-5,-6]
```

Sum:

```
1 + 12 - 5 - 6 = 2
```

```
window_sum = 2
max_sum = 2
```

---

### Slide Window

Remove **1**, Add **50**

```
[12,-5,-6,50]
```

```
window_sum = 2 - 1 + 50 = 51
max_sum = 51
```

---

Remove **12**, Add **3**

```
[-5,-6,50,3]
```

```
window_sum = 51 - 12 + 3 = 42
```

Maximum sum remains:

```
51
```

---

Maximum average:

```
51 / 4 = 12.75
```

Answer:

```
12.75
```

---

# Python Solution

```python
class Solution:
    def findMaxAverage(self, nums: list[int], k: int) -> float:

        window_sum = 0

        for i in range(k):
            window_sum += nums[i]

        max_sum = window_sum

        for i in range(k, len(nums)):

            window_sum = window_sum - nums[i - k] + nums[i]

            if window_sum > max_sum:
                max_sum = window_sum

        return max_sum / k
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

### Why?

- The first window is computed in **O(k)**.
- Each remaining element is processed exactly once while sliding the window.
- No extra array or data structure is used.

Overall complexity is **O(n)**.

---

# Why Sliding Window Works

A brute-force solution computes the sum of every subarray of length `k`, resulting in **O(n × k)** time.

Sliding Window avoids recomputing the entire sum.

Instead, it updates the window in constant time:

```
New Window Sum
=
Previous Window Sum
- Outgoing Element
+ Incoming Element
```

This reduces the overall complexity to **O(n)**.

---

# Interview Takeaway

Whenever a problem involves:

- Fixed-size subarrays
- Maximum or minimum sum
- Maximum or minimum average
- Consecutive elements of length `k`

Think of the **Sliding Window** technique first.

It is the standard optimization for fixed-size window problems, reducing time complexity from **O(n × k)** to **O(n)**.
