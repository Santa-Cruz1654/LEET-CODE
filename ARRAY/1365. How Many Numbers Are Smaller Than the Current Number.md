# 1365. How Many Numbers Are Smaller Than the Current Number

**Difficulty:** 🟢 Easy

**Topic:** Array, Sorting, Hash Map

---

## Problem Statement

Given an array `nums`, for each `nums[i]`, count how many numbers in the array are smaller than it.

Return an array where:

```python
answer[i]
```

contains the count of numbers smaller than `nums[i]`.

---

### Example 1

```python
Input: nums = [8,1,2,2,3]

Output: [4,0,1,1,3]
```

Explanation:

* 8 has four smaller numbers → 1, 2, 2, 3
* 1 has zero smaller numbers
* 2 has one smaller number → 1
* 2 has one smaller number → 1
* 3 has three smaller numbers → 1, 2, 2

---

### Example 2

```python
Input: nums = [6,5,4,8]

Output: [2,1,0,3]
```

---

## Approach 1: Brute Force

### Idea

For every number:

* Compare it with every other number.
* Count how many numbers are smaller.
* Store the count in the answer array.

---

### Dry Run

```python
nums = [8,1,2,2,3]
```

For `8`:

```python
1 < 8 ✓
2 < 8 ✓
2 < 8 ✓
3 < 8 ✓
```

Count = 4

For `1`:

```python
No smaller elements
```

Count = 0

For `2`:

```python
1 < 2 ✓
```

Count = 1

Final Answer:

```python
[4,0,1,1,3]
```

---

### Brute Force Solution

```python
class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        ans = []

        for i in range(len(nums)):
            count = 0

            for j in range(len(nums)):
                if nums[j] < nums[i]:
                    count += 1

            ans.append(count)

        return ans
```

---

### Complexity Analysis

| Metric           | Complexity |
| ---------------- | ---------- |
| Time Complexity  | O(n²)      |
| Space Complexity | O(1)       |

## Approach 2: Sorting + Hash Map (Optimized)

### Key Observation

If the array is sorted, the first position of a number tells us exactly how many numbers are smaller than it.

---

### Example

```python
nums = [8,1,2,2,3]
```

Sorted:

```python
[1,2,2,3,8]
```

Indexes:

```python
1 -> 0
2 -> 1
3 -> 3
8 -> 4
```

These indexes represent the count of smaller numbers.

---

### Building the Hash Map

```python
sorted_nums = [1,2,2,3,8]

rank = {}
```

Using `enumerate()`:

```python
for i, num in enumerate(sorted_nums):
    if num not in rank:
        rank[num] = i
```

Result:

```python
{
    1: 0,
    2: 1,
    3: 3,
    8: 4
}
```

---

### Understanding enumerate()

`enumerate()` returns both the index and value during iteration.

Example:

```python
nums = [10,20,30]

for i, num in enumerate(nums):
    print(i, num)
```

Output:

```python
0 10
1 20
2 30
```

Equivalent to:

```python
for i in range(len(nums)):
    print(i, nums[i])
```

but cleaner and more Pythonic.

---

### Dry Run

Original:

```python
nums = [8,1,2,2,3]
```

Hash Map:

```python
{
    1: 0,
    2: 1,
    3: 3,
    8: 4
}
```

Build answer:

```python
8 -> 4
1 -> 0
2 -> 1
2 -> 1
3 -> 3
```

Final Answer:

```python
[4,0,1,1,3]
```

---

### Optimized Solution

```python
class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        sorted_nums = sorted(nums)

        rank = {}

        for i, num in enumerate(sorted_nums):
            if num not in rank:
                rank[num] = i

        return [rank[num] for num in nums]
```

---

### Complexity Analysis

| Metric           | Complexity |
| ---------------- | ---------- |
| Time Complexity  | O(n log n) |
| Space Complexity | O(n)       |

### Why?

* Sorting takes O(n log n)
* Hash map creation takes O(n)
* Building answer takes O(n)

Overall:

```text
O(n log n)
```
