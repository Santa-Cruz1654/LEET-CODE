# 53. Maximum Subarray

**Difficulty:** 🟡 Medium

**Topics:** Array, Dynamic Programming (Kadane's Algorithm)

---

# Problem Statement

Given an integer array `nums`, find the **contiguous subarray** that has the **largest sum**, and return its sum.

A **subarray** consists of consecutive elements from the original array.

---

# Approach

We use **Kadane's Algorithm**, an efficient Dynamic Programming approach.

The idea is simple:

- At each element, decide whether to:
  - Start a new subarray from the current element, or
  - Extend the previous subarray.
- Keep track of:
  - `current_sum` → Maximum sum ending at the current index.
  - `max_sum` → Maximum sum found so far.

---

# Idea

For every element:

```
current_sum = max(current_element,
                  current_sum + current_element)
```

This means:

- If adding the current element makes the sum larger, continue the existing subarray.
- Otherwise, start a new subarray from the current element.

After updating `current_sum`, update the global maximum.

```
max_sum = max(max_sum, current_sum)
```

Repeat until the end of the array.

---

# Dry Run

### Input

```python
nums = [-2,1,-3,4,-1,2,1,-5,4]
```

| Index | Number | Current Sum | Max Sum | Explanation |
|------:|-------:|------------:|---------:|------------|
|0|-2|-2|-2|Initialize|
|1|1|1|1|Start new subarray|
|2|-3|-2|1|Continue subarray|
|3|4|4|4|Start new subarray|
|4|-1|3|4|Continue|
|5|2|5|5|Continue|
|6|1|6|6|Continue|
|7|-5|1|6|Continue|
|8|4|5|6|Continue|

Maximum subarray:

```
[4, -1, 2, 1]
```

Maximum sum:

```
6
```

---

# Python Solution

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:

        current_sum = nums[0]
        max_sum = nums[0]

        for i in range(1, len(nums)):

            current_sum = max(nums[i], current_sum + nums[i])

            max_sum = max(max_sum, current_sum)

        return max_sum
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

### Why?

- We traverse the array only once.
- Each element is processed exactly once.
- Only two variables (`current_sum` and `max_sum`) are used.

---

# Why Kadane's Algorithm Works

Whenever the running sum becomes worse than the current element itself,

```
current_sum + nums[i] < nums[i]
```

the previous subarray is hurting our answer.

So it's always better to discard it and start a new subarray from the current element.

This greedy decision guarantees the optimal answer in a single pass.

---

# Interview Takeaway

Whenever a problem asks for:

- Maximum or minimum contiguous subarray
- Largest sum over consecutive elements
- Best running total
- Contiguous segment optimization

Think of **Kadane's Algorithm** first.

It is the standard **O(n)** solution for maximum subarray problems and is one of the most frequently asked Dynamic Programming interview questions.
