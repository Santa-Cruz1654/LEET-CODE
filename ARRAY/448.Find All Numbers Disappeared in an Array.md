# 448. Find All Numbers Disappeared in an Array

**Difficulty:** 🟢 Easy

**Topic:** Array, Hash Set

---

## Problem Statement

Given an integer array `nums` of length `n` where:

```python
1 <= nums[i] <= n
```

Return all numbers in the range:

```python
[1, n]
```

that do **not** appear in `nums`.

---

### Example 1

```python
Input: nums = [4,3,2,7,8,2,3,1]

Output: [5,6]
```

Explanation:

The numbers from `1` to `8` are:

```python
[1,2,3,4,5,6,7,8]
```

Numbers `5` and `6` are missing.

---

### Example 2

```python
Input: nums = [1,1]

Output: [2]
```

Explanation:

The numbers from `1` to `2` are:

```python
[1,2]
```

Number `2` is missing.

---

## Approach

We use a **Hash Set** for fast lookup.

### Idea

* Store all elements of `nums` inside a set.
* Iterate through every number from `1` to `n`.
* Check whether the number exists in the set.
* If it does not exist, add it to the answer list.
* Return the final list.

Since set lookup is **O(1)** on average, checking every number is efficient.

| 6      | ❌        | Add to answer |
| 7      | ✅        | Skip          |
| 8      | ✅        | Skip          |

Answer becomes:

```python
[5,6]
```

---

## Python Solution

```python
class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        num_set = set(nums)
        ans = []

        for i in range(1, len(nums) + 1):
            if i not in num_set:
                ans.append(i)

        return ans
```

---

## Complexity Analysis

| Metric           | Complexity |
| ---------------- | ---------- |
| Time Complexity  | O(n)       |
| Space Complexity | O(n)       |

### Why?

* Creating the set takes **O(n)** time.
* Checking numbers from `1` to `n` takes **O(n)** time.
* Set lookups are **O(1)** on average.
* The set stores up to `n` elements.

Think about using a **Hash Set**.

* Fast lookup → **O(1)**
* Fast insertion → **O(1)**
* Easy existence checking
