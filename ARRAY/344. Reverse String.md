# 344. Reverse String

**Difficulty:** 🟢 Easy

**Topics:** Two Pointers, String, Array

---

# Problem Statement

Given a string represented as an array of characters `s`, reverse the string **in-place**.

You must modify the original array and use **O(1) extra memory**.

---

# Approach

We use the **Two Pointer** technique.

Place:

- `left` at the beginning of the array.
- `right` at the end of the array.

Then swap the characters at `left` and `right`.

After every swap:

```
left += 1
right -= 1
```

Continue until the two pointers meet.

---

# Idea

For:

```python
s = ["h","e","l","l","o"]
```

Start with:

```text
left  → h
right → o
```

Swap them:

```text
["o","e","l","l","h"]
```

Move inward:

```text
left  → e
right → l
```

Swap again:

```text
["o","l","l","e","h"]
```

Now the pointers have crossed, so we stop.

---

# Dry Run

### Input

```python
s = ["h","e","l","l","o"]
```

| Left | Right | Action |
|------|-------|--------|
|`h`|`o`|Swap|
|`e`|`l`|Swap|
|`l`|`l`|Stop|

Final array:

```python
["o","l","l","e","h"]
```

---

# Python Solution

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:

        left = 0
        right = len(s) - 1

        while left < right:

            tab = s[left]
            s[left] = s[right]
            s[right] = tab

            left += 1
            right -= 1
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

### Why?

- Each character is involved in at most one swap.
- We traverse approximately half of the array.
- We don't create another array or string.
- Only two pointer variables and one temporary variable are used.

Therefore:

```text
Time  → O(n)
Space → O(1)
```

---

# Why Two Pointers?

To reverse an array, we can swap elements from the **outside toward the center**.

```text
[h, e, l, l, o]
 ↑           ↑
left       right
```

After swapping:

```text
[o, e, l, l, h]
    ↑       ↑
   left   right
```

Continue until reaching the middle.

This allows us to reverse the array **in-place** without using extra memory.

---

# Interview Takeaway

Whenever a problem involves:

- Reversing an array or string
- Modifying the input **in-place**
- Comparing or swapping elements from both ends
- **O(1)** extra space

Think of the **Two Pointer Technique**.

The common pattern is:

```python
left = 0
right = len(array) - 1

while left < right:
    swap(array[left], array[right])
    left += 1
    right -= 1
```

This is one of the fundamental Two Pointer patterns to remember for interviews.
