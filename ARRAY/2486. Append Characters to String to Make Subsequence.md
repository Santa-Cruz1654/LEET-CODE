# 2486. Append Characters to String to Make Subsequence

**Difficulty:** 🟡 Medium

**Topics:** Two Pointers, String, Greedy

---

# Problem Statement

Given two strings `s` and `t`, return the **minimum number of characters** that need to be appended to the end of `s` so that `t` becomes a **subsequence** of `s`.

A subsequence is formed by deleting some characters without changing the relative order of the remaining characters.

---

# Approach

We use the **Two Pointer** technique.

We need to find how much of `t` can already be matched as a subsequence of `s`.

Use:

- `i` → pointer for `s`
- `j` → pointer for `t`

Whenever:

```python
s[i] == t[j]
```

we have successfully matched one character of `t`.

So:

```python
j += 1
```

The `i` pointer always moves forward through `s`.

At the end:

```python
len(t) - j
```

characters of `t` are still unmatched.

Those are exactly the characters we need to append.

---

# Idea

Suppose:

```python
s = "coaching"
t = "coding"
```

We try to match `t` inside `s`.

```text
s = c o a c h i n g
    ↑

t = c o d i n g
    ↑
```

Match:

```text
c ✓
o ✓
```

Then we need:

```text
d
```

but `s` doesn't contain `d` after that position.

The remaining part of `t` is:

```text
ding
```

So we need to append:

```text
"ding"
```

Number of characters:

```text
4
```

# Python Solution

```python
class Solution:
    def appendCharacters(self, s: str, t: str) -> int:

        i = 0
        j = 0

        while i < len(s) and j < len(t):

            if s[i] == t[j]:
                j += 1

            i += 1

        return len(t) - j
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

Where `n = len(s)`.

### Why?

The `i` pointer moves through `s` only once.

The `j` pointer also only moves forward.

Therefore:

```text
Time → O(len(s) + len(t))
```

More precisely, because the loop stops once either string is exhausted:

```text
O(min(len(s), len(t)))
```

which is bounded by:

```text
O(len(s) + len(t))
```

No extra data structure is used.

Therefore:

```text
Space → O(1)
```

---

# Why `len(t) - j`?

This is the key observation.

`j` represents:

> **How many characters of `t` have already been matched.**

Therefore:

```text
Total characters in t
        -
Matched characters
        =
Characters still needed
```

So:

```python
return len(t) - j
```

This problem is closely related to **392. Is Subsequence**.

```text

```

Here, we ask:

```text
How many characters of t cannot be matched inside s?
```

The same two-pointer pattern is used.

For example:

```python
while i < len(s) and j < len(t):

    if s[i] == t[j]:
        j += 1

    i += 1
```

The difference is what we return:

### 392. Is Subsequence

```python
return j == len(s)
```

### 2486. Append Characters

```python
return len(t) - j
```

# Interview Takeaway

Whenever you need to determine:

- How much of one string can be matched inside another
- Whether a string is a subsequence
- How many characters remain unmatched
- Characters that need to be appended to complete a subsequence

Think:

**Two Pointers + Greedy Matching**

The core pattern is:

```python
i = 0
j = 0

while i < len(s) and j < len(t):

    if s[i] == t[j]:
        j += 1

    i += 1
```

The important insight is:

> **`j` tells us how much of the target string has already been matched. The unmatched suffix `len(t) - j` is exactly what we need to append.**
