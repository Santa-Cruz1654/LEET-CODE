# 20. Valid Parentheses

**Difficulty:** 🟢 Easy

**Topics:** Stack, String

---

# Problem Statement

Given a string `s` containing only the characters:

```
'('  ')'  '{'  '}'  '['  ']'
```

Determine whether the string is **valid**.

A string is valid if:

1. Every opening bracket has a matching closing bracket.
2. Brackets are closed in the correct order.
3. Every closing bracket has a corresponding opening bracket.

Return `true` if the string is valid; otherwise, return `false`.

---

# Approach

We use a **Stack**.

### Why a Stack?

A stack follows the **Last In, First Out (LIFO)** principle.

Since the **most recently opened bracket must be closed first**, a stack is the perfect data structure.

---

# Idea

### Step 1

Create an empty stack.

```
stack = []
```

Create a dictionary to map closing brackets to their matching opening brackets.

```
')' -> '('
']' -> '['
'}' -> '{'
```

---

### Step 2

Traverse each character in the string.

If it is an opening bracket,

```
push it onto the stack
```

---

### Step 3

If it is a closing bracket:

- If the stack is empty,

```
return False
```

- Otherwise, remove the top element.

```
top = stack.pop()
```

Check whether it matches the corresponding opening bracket.

If not,

```
return False
```

---

### Step 4

After processing the entire string:

- If the stack is empty,

```
return True
```

- Otherwise,

```
return False
```

because some opening brackets were never closed.

---

# Dry Run

### Input

```python
s = "([])"
```

| Character | Stack | Action |
|-----------|-------|--------|
|`(`|`(`|Push|
|`[`|`([`|Push|
|`]`|`(`|Pop `[` ✓|
|`)`|Empty|Pop `(` ✓|

Stack is empty.

Answer:

```
True
```

---

### Example 2

```python
s = "([)]"
```

| Character | Stack | Action |
|-----------|-------|--------|
|`(`|`(`|Push|
|`[`|`([`|Push|
|`)`|Mismatch ❌|Expected `(` but found `[`|

Return:

```
False
```

---

# Python Solution (Using Dictionary)

```python
class Solution:
    def isValid(self, s: str) -> bool:

        stack = []

        pairs = {
            ')': '(',
            ']': '[',
            '}': '{'
        }

        for ch in s:

            if ch in "([{":
                stack.append(ch)

            else:

                if not stack:
                    return False

                top = stack.pop()

                if top != pairs[ch]:
                    return False

        return len(stack) == 0
```

---

# Alternative Solution (Without Dictionary)

```python
class Solution:
    def isValid(self, s: str) -> bool:

        stack = []

        for ch in s:

            if ch == '(' or ch == '[' or ch == '{':
                stack.append(ch)

            else:

                if len(stack) == 0:
                    return False

                top = stack.pop()

                if ch == ')' and top != '(':
                    return False

                if ch == ']' and top != '[':
                    return False

                if ch == '}' and top != '{':
                    return False

        return len(stack) == 0
```

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(n)** |

### Why?

- Each character is pushed and popped from the stack at most once.
- In the worst case (all opening brackets), the stack stores `n` characters.

---

# Why a Stack Works

The most recently opened bracket must always be the first one to close.

Example:

```
({[]})
```

Order of opening:

```
(
{
[
```

Order of closing:

```
]
}
)
```

Notice that the closing order is the **reverse** of the opening order.

This is exactly the behavior of a **Stack (LIFO)**.

# Interview Takeaway

Whenever a problem involves:

- Matching parentheses or brackets
- Nested structures
- Balanced expressions
- HTML/XML tag matching
- Undo/Redo operations

Think of using a **Stack**.

A stack is the standard and most efficient data structure for handling nested and balanced structures.
