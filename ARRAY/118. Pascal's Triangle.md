# 118. Pascal's Triangle

**Difficulty:** 🟢 Easy

**Topics:** Array, Dynamic Programming

---

# Problem Statement

Given an integer `numRows`, return the first `numRows` of **Pascal's Triangle**.

In Pascal's Triangle:

- The first and last element of every row is always `1`.
- Every other element is the sum of the two elements directly above it.

Example:

```
        1
      1   1
    1   2   1
  1   3   3   1
1   4   6   4   1
```

---

# Approach

We build the triangle **row by row**.

For each row:

1. Create a list filled with `1`s.
2. The first and last elements remain `1`.
3. Fill the middle elements using the previous row.

The relation is:

```
current[j] = previous[j - 1] + previous[j]
```

Repeat this until all rows are generated.

---

# Idea

### Step 1

Create an empty list to store the triangle.

```
triangle = []
```

---

### Step 2

For every row:

Create a row of size `row + 1`.

Example:

```
Row 0

[1]
```

```
Row 1

[1,1]
```

```
Row 2

[1,1,1]
```

---

### Step 3

Fill the middle elements.

For every position except the first and last:

```
current[j] =
triangle[row-1][j-1]
+
triangle[row-1][j]
```

---

### Step 4

Append the completed row to the triangle.

Continue until all rows are generated.

# Python Solution

```python
class Solution:
    def generate(self, numRows: int) -> list[list[int]]:

        triangle = []

        for row in range(numRows):

            current = [1] * (row + 1)

            for j in range(1, row):

                current[j] = (
                    triangle[row - 1][j - 1]
                    + triangle[row - 1][j]
                )

            triangle.append(current)

        return triangle
```

---

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n²)** |
| Space Complexity | **O(n²)** |

### Why?

- We generate all rows from `1` to `numRows`.
- Each row contains up to `numRows` elements.
- The total number of elements generated is:

```
1 + 2 + 3 + ... + numRows
```

which equals **O(n²)**.

The output itself also requires **O(n²)** space.

---

# Why This Works

Each element (except the edges) depends only on the previous row.

```
Current Row

      x

Previous Row

   a     b

x = a + b
```

Since every row is built from the one above it, we can construct the entire triangle iteratively.

# Interview Takeaway

Whenever a problem involves:

- Building rows from previous rows
- Triangular patterns
- Each state depending on the previous state
- Incremental construction

Think of **Dynamic Programming**.

Pascal's Triangle is one of the classic introductory Dynamic Programming problems because each value is derived from previously computed values.
