# 217. Contains Duplicate

**Difficulty:** 🟢 Easy

**Topic:** Array, Hash Set

---

## Problem Statement

Given an integer array `nums`, return:

* `True` if any value appears at least twice in the array.
* `False` if every element is distinct.

### Example 1

```python
Input: nums = [1,2,3,1]

Output: True
```

Explanation:

The element `1` appears more than once.

### Example 2

```python
Input: nums = [1,2,3,4]

Output: False
```

Explanation:

All elements are unique.

---

## Approach

We use a **Hash Set** to keep track of numbers we have already seen.

### Idea

* Create an empty set called `seen`
* Traverse through each number in the array
* If the number already exists in `seen`, a duplicate is found
* Return `True` immediately
* Otherwise add the number to the set
* If the loop finishes without finding duplicates, return `False`

Since set lookup is **O(1)** on average, this approach is very efficient.

## Python Solution

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        seen = set()

        for num in nums:
            if num in seen:
                return True

            seen.add(num)

        return False
```

---

## Alternative One-Liner

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return len(nums) != len(set(nums))
```

### Why It Works

A set automatically removes duplicate values.

Example:

```python
nums = [1,2,3,1]

set(nums)
```

Output:

```python
{1,2,3}
```

Notice that the duplicate `1` is removed.

If the size of the set is smaller than the size of the original array, duplicates existed.

## Complexity Analysis

| Metric           | Complexity |
| ---------------- | ---------- |
| Time Complexity  | O(n)       |
| Space Complexity | O(n)       |

### Why?

* We visit each element exactly once.
* Set lookup and insertion take **O(1)** average time.
* In the worst case, all elements are unique and stored in the set.
