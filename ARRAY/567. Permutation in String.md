# 567. Permutation in String

**Difficulty:** 🟡 Medium

**Topics:** Sliding Window, Hashing, String, Frequency Count

---

# Problem Statement

Given two strings `s1` and `s2`, return **true** if `s2` contains a **permutation** of `s1`; otherwise, return **false**.

A permutation of `s1` means that some substring of `s2` has:

- The same length as `s1`
- The same frequency of every character

---

# Approach

We use the **Sliding Window** technique along with **frequency arrays**.

The idea is:

1. Count the frequency of every character in `s1`.
2. Create a window of the same length in `s2`.
3. Compare the two frequency arrays.
4. Slide the window one character at a time:
   - Remove the leftmost character.
   - Add the new rightmost character.
5. If the frequency arrays ever become identical, a permutation exists.

---

# Idea

### Step 1

Create two frequency arrays of size **26**.

```
need   -> frequency of characters in s1
window -> frequency of current window in s2
```

---

### Step 2

Fill `need` using `s1`.

Example:

```
s1 = "ab"

need:

a -> 1
b -> 1
others -> 0
```

---

### Step 3

Build the first window of length `len(s1)` in `s2`.

Example:

```
s2 = "eidbaooo"

First window:

"ei"
```

Count its character frequencies.

---

### Step 4

Compare

```
need == window
```

If equal,

```
return True
```

Otherwise, slide the window.

---

### Step 5

For every slide:

Remove the outgoing character.

```
window[left] -= 1
```

Add the incoming character.

```
window[right] += 1
```

Compare the frequency arrays again.

If they match, a permutation has been found.

# Python Solution

```python
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:

        if len(s1) > len(s2):
            return False

        need = [0] * 26
        window = [0] * 26

        for ch in s1:
            need[ord(ch) - ord('a')] += 1

        for i in range(len(s1)):
            window[ord(s2[i]) - ord('a')] += 1

        if need == window:
            return True

        for i in range(len(s1), len(s2)):

            left = ord(s2[i - len(s1)]) - ord('a')
            right = ord(s2[i]) - ord('a')

            window[left] -= 1
            window[right] += 1

            if need == window:
                return True

        return False
```

# Complexity Analysis

| Metric | Complexity |
|---------|------------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

### Why?

- Building the frequency arrays takes **O(m)** where `m = len(s1)`.
- Sliding the window across `s2` takes **O(n)**.
- Comparing two frequency arrays of size **26** takes constant time.

Overall complexity is **O(n)**.

---

# Why Frequency Arrays?

Instead of generating every permutation of `s1` (which is extremely expensive), we compare character frequencies.

If two strings have:

- The same length
- The same frequency of every character

then they are permutations of each other.

Using a fixed-size array of length **26** makes these comparisons very efficient.

# Interview Takeaway

Whenever a problem involves:

- Checking if one string contains an anagram of another
- Finding permutations inside a string
- Comparing character frequencies
- Fixed-length substring matching

Think of combining:

- **Sliding Window**
- **Frequency Array (Hashing)**

This is the standard **O(n)** solution for permutation and anagram-based string problems.
