# 125. Valid Palindrome

**Difficulty:** 🟢 Easy

**Topic:** Two Pointers, String

---

## Problem Statement

A phrase is considered a palindrome if, after:

* Converting all uppercase letters to lowercase
* Removing all non-alphanumeric characters

it reads the same forward and backward.

Given a string `s`, return `true` if it is a palindrome, otherwise return `false`.

## Approach

We use the **Two Pointer** technique.

### Idea

* Place one pointer at the beginning (`left`)
* Place another pointer at the end (`right`)
* Skip all non-alphanumeric characters
* Compare characters ignoring case
* If characters differ, return `False`
* Otherwise move both pointers toward the center

Continue until the pointers meet.

---

## Dry Run

### Input

```python
s = "A man, a plan, a canal: Panama"
```

### Initial State

```text
left  = 0  -> 'A'
right = 29 -> 'a'
```

Compare:

```text
a == a
```

Move pointers inward.

Skip spaces, commas, and colons.

Eventually comparisons become:

```text
m == m
a == a
n == n
...
```

All comparisons match.

Result:

```python
True
```

---

## Python Solution

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left = 0
        right = len(s) - 1

        while left < right:

            while left < right and not s[left].isalnum():
                left += 1

            while left < right and not s[right].isalnum():
                right -= 1

            if s[left].lower() != s[right].lower():
                return False

            left += 1
            right -= 1

        return True
```

---

## Complexity Analysis

| Metric           | Complexity |
| ---------------- | ---------- |
| Time Complexity  | O(n)       |
| Space Complexity | O(1)       |

### Why?

* Each character is visited at most once.
* No extra string or array is created.
* Only two pointers are used.

## Interview Takeaway

Whenever a problem involves:

* Palindromes
* Comparing both ends of a string
* Symmetry checks

Think of the **Two Pointer Technique** first.
