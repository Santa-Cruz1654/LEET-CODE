# 268. Missing Number

**Difficulty:** 🟢 Easy

**Topic:** Array, Hash Set

---

## Problem Statement

Given an array `nums` containing `n` distinct numbers in the range `[0, n]`, return the only number that is missing from the range.

### Example 1

```python
Input: nums = [3,0,1]

Output: 2
```

Explanation:

The numbers should be:

```python
[0,1,2,3]
```

But `2` is missing.

### Example 2

```python
Input: nums = [0,1]

Output: 2
```

Explanation:

The numbers should be:

```python
[0,1,2]
```

But `2` is missing.

---

## Approach

We use a **Hash Set** for fast lookup.

### Idea

* Store all numbers from `nums` inside a set.
* Iterate through every number from `0` to `n`.
* Check whether the current number exists in the set.
* The first number not found is the missing number.
* Return it immediately.

Since set lookup takes **O(1)** on average, the solution is efficient.

## Python Solution

```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        num_set = set(nums)

        for i in range(len(nums) + 1):
            if i not in num_set:
                return i
```

---

## Why Does This Work?

The array contains numbers from:

```python
0 to n
```

Exactly one number is missing.

By placing all existing numbers into a set, we can quickly check whether each number in the expected range exists.

The one that does not exist is the answer.

---

## Complexity Analysis

| Metric           | Complexity |
| ---------------- | ---------- |
| Time Complexity  | O(n)       |
| Space Complexity | O(n)       |

### Why?

* Building the set takes **O(n)**.
* Checking numbers from `0` to `n` takes **O(n)**.
* Set lookups are **O(1)** on average.
* The set stores up to `n` elements.

in **O(1)** average time.
